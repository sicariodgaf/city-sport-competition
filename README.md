# City Sport Competition

Проект базы данных для организации городских спортивных соревнований.

## Описание

База данных предназначена для хранения информации о соревнованиях, видах спорта, дисциплинах, участниках, командах, судьях, регистрациях и результатах.

## Используемые технологии

- PostgreSQL 18
- SQL
- Git
- Atom

## Структура проекта

- database.sql — структура базы данных и тестовые данные.
